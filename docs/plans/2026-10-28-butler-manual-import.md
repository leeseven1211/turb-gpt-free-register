# Butler 手动补充本地库存

在邮箱资源池新增“从 Butler 导入”，用户选择现有支持的邮箱类型、母/子邮箱和数量，可按域名、分组筛选；保留其他来源的粘贴导入。首版启用已有永久归属合同的 iCloud HME，不把普通短租约当作长期库存。

1. Butler 新增 consumer policy 限定的只读候选接口。候选必须健康、未使用、未归属，只返回严格收件和固定身份字段，不生成邮箱。
2. Turb 预览只读取候选并跨本地来源排重；预览不领取、不写密钥。开始导入前持久保存批次和所有原候选、归属、收件配置。
3. 后台逐地址导入，每项独立提交。重复点击、HTTP 超时和服务重启后的继续操作均恢复原批次、原地址与 acquisition，不领取替补。
4. 新增按钮、选择弹窗、预览和进度。保存批次身份，关闭弹窗或刷新后可恢复；成功后更新本地可用数。
5. 在隔离 PG schema 下验证策略隔离、排重、幂等、超时和部分成功；浏览器验证操作与恢复。生产发布保留 Oracle 文件漂移和本地私有文件，空闲门禁后发布并检查健康。

注册、收件与结果回报继续使用现有本地库存和固定 Butler 连接，不引入注册时远端领取或自动生成。
