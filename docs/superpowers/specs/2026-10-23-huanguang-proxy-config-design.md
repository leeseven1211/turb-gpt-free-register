# 幻光提链手动代理池配置

用户需要自行填写幻光的入口和出口代理池，避免每次只能提交本地统一代理池领取的单个候选。

## 实现范围

- 在现有「配置 → 提链 → 幻光」增加入口代理池和出口代理池，字段分别为 `EXTRACT_LINK_HUANGUANG_ENTRY_PROXIES`、`EXTRACT_LINK_HUANGUANG_EXIT_PROXIES`。
- 每行一条完整代理地址，支持 HTTP、HTTPS、SOCKS5、SOCKS5H 及认证；每侧最多 500 条，保存时去重并校验。
- 按侧选择来源：填写的侧传入完整列表；留空的侧沿用统一代理池领取一条 IN 线路。手动地址的印度出口由用户提供，不自动推断或改写国家。
- 两字段是敏感的多行配置，仅保存到 `.env`，API 不回显地址，快照不包含地址；留空未修改保留原值，明确清除后回退自动领取。
- 保存后对下一次创建或重跑生效；同步已有远端任务不换代理、不创建任务。
- 本次不扩展幻光自动支付能力。

## 方案选择

直接复用现有敏感多行配置控件，并把完整列表传给幻光已有的 `entry_proxies`、`exit_proxies`。相比新增独立代理管理页，这个方案范围小，符合用户自行填写的要求；保留按侧回退，兼容现有自动领取行为。

## 验收

配置保存、清空、校验和敏感数据隔离测试通过；多个候选完整传参、单侧回退、双侧回退及原有单代理兼容测试通过。真实浏览器确认字段可填写并校验，重启本地服务后确认健康检查。本次不消耗 CDK，不发起真实提链或支付。
