# 总览每日注册统计设计

用户已确认本方案，并授权开发完成后直接合并到本地 main。

- 在服务脉搏下新增全宽统计区域，默认近 7 天，可选择近 30 天或自定义日期，统计时区固定为北京时间。
- 柱状图显示每日注册任务数；明细按日展示总数、成功、部分成功、失败、进行中、取消、产出账号数和当前套餐分布。无任务日期仍展示零。
- 任务计数使用 `registration_jobs.id`，只包含 `registration` 和 `registration_resume`，空类型兼容为注册。显式新建的重跑记录计入新任务，任务内部重试不重复计数。
- 套餐按当天任务关联账号去重，含归档账号，复用总览现有互斥套餐分类，显示最近成功查询后的当前快照；同一账号可以出现在不同日期，日期区间汇总按账号去重。
- 每日行和日期区间均提供“新建查套餐批量（N）”。范围沿用现有 Plus 无优惠筛选，只带入未归档账号；进入原有批量新建页，预填操作、账号范围和名称，由用户选择创建并执行或创建并暂停。
- 统计名单与新建页范围必须使用同一个注册任务日期口径，不能用账号创建日期代替。复用账号查询与批量固定名单机制，不向浏览器传大量账号 ID。
- 注册主流程、执行参数、重试和状态流转均保持不变；本次只修改聚合读取、展示和批量新建页预填。
- 本次授权包括代码 review、提交和合并本地 main，不包含推送、部署或服务重启。
