# 第五阶段：总览、注册与提链页面迁移

用户于 2026-11-17 批准同步开始总览、注册、提链页面迁移。本批现已完成本地实现、兼容、独立审查与验收，最终页面表和验证边界见[第五阶段完成报告](phase5-completion.md)。下文保留已批准实施范围。本批沿用已确认的架构与列表交互规范；新增业务行为、操作流程或独立 UI 改进须另列建议，讨论后才纳入。

## 边界与交付

1. 总览：保留能力可见性、全部卡片、布局持久化、自定义显示、排序和尺寸调整；迁入独立 Vue 页面、类型化 API 和生命周期。
2. 注册：保留来源、数量、并发、调试、新建批次、批次进度、日志与诊断、停止、取消、删除、重试和手动 OTP；只迁移页面，不修改注册驱动、认证流程与恢复策略。
3. 提链：迁移完整工作台和独立统计菜单，保留候选筛选、批次创建/停止、批次与任务独立分页、详情、支付入口、复制/导出、原单状态查询及既有读缓存。支付成功、远端受理、Plus 确认与未知状态保持各自含义。

各页唯一状态所有者，API 与展示分离；旧全局入口保留轻量兼容外观。复用表头筛选、计数行筛选条件、两行单元格、短结果和真实分页组件。标识符使用精确解码；页面隐藏停止读取，晚响应不得覆盖新页面；写入受理回执与加载失败分开处理，禁止意外重放写入。
