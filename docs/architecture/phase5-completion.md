## 公共架构与交互

- 列名打开筛选；已选条件并入数据计数行；单元格最多两行、单行内容垂直居中；列表结果/错误使用短分类，完整证据保留在详情。
- 有准确总数的列表复用数字分页、跳页和每页条数，页码居中、计数靠右。批量页继续使用接口真实提供的游标，未模拟任意页跳转。
- 页面 API 客户端、数据 owner 和展示组件分开；旧页面主体退出，旧全局入口通过薄桥接进入当前 owner。新桥接负责按需加载、导航代次和加载失败重试。
- 页面离开停止读取与轮询，晚响应不能覆盖新页面或重新打开弹窗。共享原生弹层负责焦点、Escape、背景锁及恢复；账号旧查活日志/二维码继续使用明确兼容入口。
- 注册任务兼容地址 `#register/tasks`、配置跳转和历史恢复保持同一视图身份。公开 job、Task、Run 与 batch ID 保留精确十进制值。
- 写入受理回执与页面刷新失败分开处理；同一次未知提交的显式重试沿用身份，成功后新的明确提交获得新身份。参数校验失败或取消确认不能消费旧成功回执。
