# 普通列表与任务详情

普通列表用于比较多条记录。任务详情用于回答某次运行发生了什么、结论来自哪条证据。以下约定沿用候选版本 `59795268` 的设计。当前任务中心已经在模板和 JavaScript 中实现了紧凑行、表头筛选和分页。Vue 公共组件也已入库，各页面的实际接入情况见文末。

## 普通列表

- 页面沿用全站标题。列表依次安排工具栏、数据和分页。工具栏保留数量、当前筛选和本页可执行的操作。
- 单元格默认最多两行。有主次字段时各占一行，只有一个长字段时最多占两行。上下内边距相等，单行 ID 和状态与同一行的两行文字垂直居中。给省略的内容提供完整提示，键盘和触屏用户也应能通过展开或详情读取全文。
- 任务中心的“结果 / 错误”列默认显示语义短语，主次文字合计最多 10 个 Unicode 字符。执行状态和目标结果分别取值。例如提链成功、支付失败时保留两个事实，当内部结果是 `request_unknown` 时，执行状态按现有接口显示“失败”，详情保留远端结果仍待核验的事实。完整原因、错误码和历史证据放入展开内容或详情。两行限制只用于收起的单元格。
- 有筛选能力的列以列名作为入口。应用条件后高亮表头，条件标签与数量同栏，可逐项清除，也可清空。条件多时标签横向滚动。窄屏保持表格在自身容器内滚动，紧凑筛选入口与桌面共用字段和取值。提交条件沿用该列表已有的单选、多选和日期范围契约。

## 分页

| 接口提供的数据 | 页面行为 |
| --- | --- |
| 精确总数、页码和每页条数 | 提供前后页、首末页和邻近页码、跳页、当前范围、总数及每页条数。Enter 与跳转按钮等效，越界页归到边界，无效输入在原处提示。改变筛选或每页条数后从第一页读取。 |
| 游标和下一页标志或 `next_cursor` | 显示本页条数，按返回的游标读下一页。能返回时使用已访问的游标回上一页或首页。只有游标的接口不展示总页数或任意数字跳转。 |

宽屏把导航相对整个页尾居中，统计靠右。空间不足时分行，页码列表在手机上保留当前页／总页数、前后页和跳页。空结果和正在加载时应禁用不可用的导航。

## 任务详情

从任务行打开详情，先确认任务与所选运行（Run），再查看摘要、失败位置和阶段。多个 Run 要能切换，阶段、事件和日志都应对应所选 Run。点击阶段可以缩小事件和日志范围，步骤详情保留具体原因、尝试和子步骤。当前详情提供“事件时间线”“运行日志”“诊断资源”三个视图，时间按浏览器时区显示。[详情模板](../../webui/templates/index.html) · [详情实现](../../webui/static/js/pages/operations/page.js)

阶段状态取自已记录的进度、事件和回执。详情按证据展示阶段依赖、记录先后、子任务和所属运行。缺少关系字段的历史记录只展示已有事实。明确跳过、未执行、记录不足和待确认分别展示。后续重试成功时保留先前失败的尝试。相同原因可在详情归并，具体原因不同的证据应分别可读。列表轮询期间应保留用户正在查看的运行、展开状态和阅读位置。[任务观测与证据契约](task-observation.md)

详情弹窗支持键盘操作。关闭步骤详情时应回到打开它的控件，关闭任务详情时应回到仍然可见的行入口。多个弹窗打开时，最后一个弹窗关闭后才恢复背景滚动。切离所属页面时关闭详情和筛选浮层，已隐藏的入口不接收焦点。

## 当前接入范围

| 入口 | 当前实现 |
| --- | --- |
| 任务中心、注册任务详情 | 任务中心由 `#accountTasksPanel` 和 `renderAccountTasks()` 渲染，表头提供 ID 等筛选，数量旁可逐项清除条件。结果短语由 `list-display.js` 生成。注册任务和任务中心共用 `#accountTaskLogPanel`。 |
| 注册任务、账号、邮箱库存、Codex 和任务中心的页码列表 | 这些分页状态在 `common.js` 的 `PAGERS` 中登记，使用 `_renderPager`。账号和 Codex 等表格已使用模板的列名筛选。各页仍由原页面脚本渲染。 |
| 批量任务 | 批次列表和目标列表由批量页面脚本维护游标及上一页历史。 |
| 历史子邮箱 | 邮箱子菜单和母邮箱行都进入同一个 Vue 列表，复用表头筛选、两行单元格和跳页控件。 |
| 总览、代理与流量、提链统计 | 左栏按需加载这三个 Vue 页面。代理页包含库存、租约和流量记录，支持表头筛选及分页。提链统计按北京时间、日期范围和平台展示历史数据。 |
| 注册 Live、提链工作台和配置 | 这些入口沿用现有模板和页面脚本。 |

Vue 页面接入时可复用 `ListCell`、`ListResult`、`FilterPopover`、`ListFilterSummary`、`ListPagination` 和 `CursorPagination`。组件负责排版、交互和分页事件，具体页面负责请求、筛选值和记录身份。当前模板筛选由 `common.js` 处理。[Vue 公共组件](../../frontend/src/components/) · [模板筛选与分页](../../webui/static/js/shared/common.js) · [批次游标实现](../../webui/static/js/pages/bulk/page.js)

核对任务列表布局时，现有用例覆盖 1440 和 375 像素下的表头筛选、两行行高、提示全文和展开等待原因。页码边界与跳页另有独立用例。[任务行布局用例](../../tests/operations/test_task_list_row_layout.py) · [分页用例](../../tests/webui/test_offset_pager.cjs)
