# Butler 子邮箱统一管理生产验收

2026-10-27 已部署。Butler 管理子邮箱生成、累计额度、库存、分配和结果登记；Turb 只导入、领取和使用。管理入口为 [Email Butler → 子邮箱](https://codex-auth.leeseven.com/email-butler/derived.html)。

## 已上线行为

- HME 默认每个母邮箱累计 3 个子邮箱、随机后缀 6 位；策略在 Butler 修改。失败、超时、结果未知或删除展示记录均不退回已发行额度。
- 新领取在 Turb 发 HTTP 请求前持久保存 acquisition 和业务归属。响应丢失只恢复原意图；并发提交、重复结果登记和过期租约不能导致换号或重新发放旧地址。
- 192 个历史子邮箱全部导入 Butler：144 used、48 reserved，原完整地址、owner、acquisition、source 和固定收件 profile 保留。135 个与已注册账号精确匹配的子地址保留 OpenAI 服务标签，其余地址不推测成功。
- Turb 的“历史子邮箱”页只读；旧生成和库存修改 API 返回 410，旧配置不能重新开启本地生成。旧已保存请求和既有账号仍可恢复。
- Butler 原 Outlook 别名管理保留。当前 Turb 接受具备严格完整收件声明的 HME 子身份；其他 provider 的子身份在对应精确收件契约接通前拒绝使用，普通邮箱沿用原路径。

## 发布与迁移

Butler 版本为 `f0e0506`，Turb 功能版本为 `58c2c94`，均只在本地提交，未 push。Oracle 根据现网快照与功能基线三方合成，仅安装 12 个审核文件；MailCom、域名匹配和现网界面差异保留。新增 `0005_derived_inventory.sql` 中的独立账本，不重建旧表。

Oracle 备份目录为 `/srv/backups/email-butler-derived-20261027T130252Z`，保存数据库 dump、旧源码、文件属性、发布清单及迁移回执。迁移逐条核对 3,838 个旧 HME 身份与固定路由、3,543 条旧服务登记完整 JSON 和计数；历史导入执行两次验证幂等。若首次发布失败后账本已有数据，再次部署必须先显式对账，不能直接重新 bootstrap。

生产生成 3 个真实可用子邮箱，并以原 request ID 重放，结果完全一致、累计额度仍为 3；未为验收领取或消耗邮箱。验收时共 195 个子邮箱，3 可用、192 已发行，3,650 个母身份。母身份记录数量不代表全部来源可用；新生成和领取仍受来源活动状态、排除规则和固定路由限制。

升级后正常执行一次 iCloud 同步，新增 4 个母身份，历史归属、服务登记和 3 个可用子地址均未改变，另保留定时同步。六项相关 unit 为 Butler、mail-pipeline、goimapnotify、iCloud sidecar、自动创建 worker 和同步 timer。Turb 在活跃业务运行、未知执行意图、有效账号/OTP 租约和即将执行队列均为零的窗口升级重启；用户队列未被取消。34 个变更文件的生产与工作区哈希一致，健康、就绪和登录接口均返回 200。启动约需 14 秒，首次 10 秒就绪窗口不足；随后独立复核通过，初始超时与后续成功回执分别保留。

## 验证与性能

- Butler 开发源隔离 PostgreSQL 全套 220 项通过；包含真实多连接/多进程生成与领取、旧快照写回、服务标签与成功上报并发、权限、迁移和只读身份恢复。
- 最终 Oracle 合成源 179 项通过，含 MailCom 回归。所有数据库测试只使用独立 `mail_prepare_20261027` 和临时 schema。
- Turb 最终客户端与消费测试 34 项、前端 43 项通过；相关恢复、来源回退、手动领取和历史只读测试通过。手动领取在发请求前保存 UUID，未知结果和页面刷新继续同一请求。
- 最终跨仓真实 PG/HTTP 联调通过 15 项消费检查与 4 项管理检查，另逐行验证 192 条历史二次导入。合成 MIME 按完整目标地址取码，母地址拒绝子地址验证码，OTP guard 使用 nullable local binding，不创建伪本地分配。
- 生产认证能力与只读 resolve 验收通过，恢复前后身份及 acquisition 不变；移动和桌面管理页均成功加载，移动端无横向溢出。

Oracle 本机采样库存接口 5 次为 1.105–1.135 秒，中位 1.117 秒；能力查询约 32 毫秒，只读身份恢复约 1.498 秒。通过 SSH 隧道生成 3 个库存约 1.403 秒，幂等重放约 1.719 秒。这些数字是管理/身份 API 耗时，不是邮件投递或验证码到达耗时。本轮未再次触发外部验证码；实际母子收件与验证码性能见[上一轮收件验收](2026-10-27-hme-receipt-validation.md)。

私密导出、请求及详细回执保存在忽略目录，权限为 0600；文档不包含 Key、Cookie、完整批量邮箱、OTP 或邮件正文。
